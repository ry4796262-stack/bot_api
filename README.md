# Telegram PC Control

Telegram-бот на Python для удаленного мониторинга состояния компьютера и управления им в реальном времени.

## Основные возможности

*  Мониторинг системы (`/stats`):** Отслеживание нагрузки на процессора (`CPU`), оперативной памяти (`RAM`), диска (`/C`) и сетевого трафика (отправленные/полученные мегабайты) в реальном времени.
*  Скриншот экрана (`/screenshot`):** Мгновенный скриншот и отправка изображения прямо в чат Telegram.
*  Удаленное выключение (`/shutdown`):** Безопасное выключение компьютера по команде.
*  Автоматическая защита: Перед запуском бота, пользователь сам добавляет id своего телеграмм, для защиты от постороннего вмешательства.

## Технологии и библиотеки

Проект написан на языке **Python** с использованием следующих библиотек:
* **pyTelegramBotAPI** — для работы с Telegram Bot API.
* **psutil** — для сбора системных характеристик пк.
* **pyautogui** — для создания скриншотов экрана.


## Установка и запуск

1. **Клонируй репозиторий или скачай файлы проекта.**

2. **Установи необходимые библиотеки через терминал.**
   pip install pyTelegramBotAPI psutil pyautogui

3. **Вставьте токен бота и ваш id.**
